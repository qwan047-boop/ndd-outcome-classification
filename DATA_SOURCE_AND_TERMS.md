# Historical registry extract and applicable terms

The source is ClinicalTrials.gov, maintained by the U.S. National Library of Medicine, using API v2 fields. The package includes a selected field-level historical extract for 670 NCTs and 4,653 outcomes, 3,412 eligible outcomes, and research-derived annotations, targets and partitions. It excludes source contact modules and administrative data not used for this task. Registry strings were retained, derived fields identified separately, and original local file paths replaced by basenames.

The original study URL is preserved for each NCT. Fourteen archived page fingerprints and acquisition-batch identifier 20261104T100316Z are recorded in data/registry_page_provenance.json. A batch identifier is not an independently verified exact extraction event or a single registry processing timestamp. Per-study posted and update dates are retained where provided in registry_status_fields. The common historical extraction cutoff was not recovered.

These are frozen historical research inputs. They must not be presented as current trial status. ClinicalTrials.gov changes over time, so a current API request may differ. No new registry download was used to replace the frozen evidence. Source-provided dates, the historical batch identifier, the missing common date and these transformations are disclosed rather than reconstructed.
