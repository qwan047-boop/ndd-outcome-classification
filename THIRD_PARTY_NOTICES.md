## Web-label source

The package includes original machine output JSON and neutral evidence keys. The source is human-triggered ChatGPT web sessions, with author-confirmed interface name GPT-6.1 Sol and archived model slug gpt-6.1-sol-wm. No exact fixed backend snapshot or model weight license is inferred. Ten successful messages and one empty attempt are distinguished. Private transcript PDFs, share links, real message and parent IDs, raw browser responses and account material are excluded.
